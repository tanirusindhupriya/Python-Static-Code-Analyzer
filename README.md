# Python Static Code Analyzer

## Project Description

Python Static Code Analyzer is a Python-based tool that analyzes Python source code and identifies common code quality issues.

## Features

- Detects unused imports
- Detects long functions
- Detects excessive nesting
- Detects naming problems
- Calculates a basic complexity score
- Generates JSON analysis reports
- Generates HTML analysis reports

## Technologies Used

- Python
- AST
- Regex
- JSON
- HTML
- Static Code Analysis

## Project Files

- `analyzer.py` - Main analyzer program
- `sample.py` - Sample Python source code
- `report.json` - Generated JSON report
- `report.html` - Generated HTML report

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```text
python analyzer.py
